# Как собрать APK

1. Установи Godot 4.x.
2. Открой папку проекта `SobrJumper` через Godot.
3. Установи Android Studio и Android SDK.
4. В Godot открой `Editor -> Manage Export Templates` и установи шаблоны экспорта.
5. Открой `Project -> Install Android Build Template`.
6. Открой `Project -> Export`, добавь preset `Android`.
7. Укажи package name: `com.sobr.jumper`.
8. Нажми `Export Project` и сохрани `SobrJumper.apk`.

Я не использовал название Mario, персонажей Nintendo, музыку или спрайты Nintendo, чтобы игра была юридически безопасной.
