# Как бесплатно собрать APK через GitHub Actions

Это самый простой способ, если на телефоне/ПК не получается собрать APK вручную.

1. Создай бесплатный аккаунт на GitHub.
2. Создай новый репозиторий, например `SobrJumper`.
3. Загрузи туда всё содержимое папки `SobrJumper` из этого архива.
4. Открой вкладку `Actions`.
5. Выбери workflow `Build Android APK`.
6. Нажми `Run workflow`.
7. Через несколько минут открой завершённую сборку.
8. Внизу скачай артефакт `SobrJumper-APK`.
9. Внутри будет файл `SobrJumper.apk`.

APK будет debug-сборкой, её можно установить на Android для теста. Для публикации в Google Play потом нужна release-сборка с личной подписью.
