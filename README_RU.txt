СОБР ПРЫГУН — готовый стартовый проект 2D ретро-платформера для Godot 4.

Внутри уже есть:
- главное меню;
- первый уровень;
- герой с бегом и прыжком;
- монеты;
- враги;
- финиш уровня;
- кнопки управления под Android;
- экран победы.

Открой проект в Godot 4, запусти MainMenu.tscn или экспортируй в APK по инструкции docs/BUILD_APK_RU.md.
